¿Qué se relaciona con el rendimiento (kg/ha) por módulo?

Aqu Anqa · Sekoya Pop · 2025 (único año con riego real medido) · grano módulo × semana ISO · generado 2026-08-06

1. Objetivo y método 2. Datos de entrada 3. Cómo se entrenó y validó 4. Ranking de importancia 5. Cómo se comporta cada variable 6. Hallazgos 7. Qué NO se puede afirmar

1Objetivo y método

La pregunta de negocio: de todo lo que se mide hoy en campo (clima, riego, edad del fruto), ¿qué se relaciona más con cuántos kilos por hectárea produce un módulo en una semana? No es una pregunta que se responda mirando una tabla — hay 17 variables cruzándose al mismo tiempo. Para eso se usa SHAP (SHapley Additive exPlanations): en vez de mirar una correlación variable-por-variable, se entrena un modelo (XGBoost, árboles de decisión) que aprende de las 471 combinaciones reales de módulo-semana, y SHAP reparte la predicción de cada fila entre las variables que la explican — cuánto sumó o restó cada una, en las mismas unidades del resultado (kg/ha).

La diferencia con el plan original (Estimación de Arándanos con IA.md, Paso 3) es que aquí cada número que sigue se validó contra datos que el modelo no vio antes de decidir si mostrarlo. La primera versión — pronosticar la semana siguiente — no pasó esa prueba y se descartó (detalle en §7). La que sí se muestra explica la semana actual, no pronostica el futuro.

3Cómo se entrenó y se validó

Modelo: XGBoost (300 árboles, profundidad máxima 4, tasa de aprendizaje 0,05) — elegido porque maneja de forma nativa variables con datos faltantes y relaciones no lineales (un efecto de riego que ayuda hasta cierto punto y luego deja de sumar, por ejemplo), sin necesidad de asumir que la relación es una línea recta.

La validación es la parte que de verdad importa — un modelo siempre puede ajustar bien los datos con los que se entrenó; la pregunta es si sirve para algo con datos que no vio. Se probó de dos formas, cada vez más exigente:

(a) 5 particiones aleatorias

—

Se separan las 471 filas en 5 grupos al azar; cada grupo se predice con un modelo entrenado SOLO con los otros 4. R² = qué fracción de la variación real se explica (0 = nada, 1 = perfecto).

(b) Deja-un-módulo-fuera

—

Más dura: cada módulo se predice con un modelo que nunca vio ese módulo. Si esto es positivo, el patrón no depende de "memorizar" el módulo — generaliza a uno nuevo.

5Cómo se comporta cada variable

El ranking anterior dice cuánto pesa cada variable, en promedio — no dice cómo. Estos gráficos muestran, para las 6 variables con más peso, cada una de las 471 semanas reales: en el eje horizontal, el valor que tuvo esa variable esa semana; en el eje vertical, cuántos kg/ha sumó o restó (SHAP) esa semana en particular. La línea gruesa es el promedio por tramo — la forma real de la relación, no una recta asumida.

6Hallazgos

7Qué NO se puede afirmar con esto

No es un pronóstico. Explica el kg/ha de la misma semana, con las variables de esa misma semana — no predice la semana siguiente. Se probó esa versión primero (mismo modelo, mismo método, prediciendo t+1) y no validó: R² = −0,33 (corte temporal) y R² = −0,09 (5-fold por campaña) — peor que predecir el promedio histórico. Se descartó sin mostrarla como si "probara" algo.
No es causal. Es una relación estadística validada por generalización (el modelo funciona con módulos y semanas que no vio), no un experimento controlado. No se puede decir "si aumento el riego X mm, la cosecha sube Y kg" con la certeza de un ensayo agronómico diseñado para eso.
Alcance limitado. Solo 2025 (único año con riego real cargado). Sin fenología (flores, estados, diámetro de baya): esas tablas solo existen para la campaña 2026 y no son comparables entre años. Sin riego para M16-M18 ni Aqu Anqa 6 (sin fuente de datos).
